\section{Conclusion}
\label{sec:conclusion}

We presented NeuroCode, a heterogeneous host-device co-scheduled systems architecture that unlocks autonomous software engineering on consumer edge hardware. By offloading structural Code Property Multigraph construction to the Host CPU and solving a constrained topological knapsack problem, NeuroCode reduces prompt tokens by 97.1\%, cuts developer cost by 97.1\%, and operates within a strict 961.2\,MB peak VRAM envelope on an NVIDIA GeForce RTX 3050 Laptop GPU. Heterogeneous host-accelerator co-scheduling provides a practical, robust path toward democratizing on-device autonomous software engineering.
